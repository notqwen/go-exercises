# Задание 2. Практика 17.11.2026 — Подсчёт количества слов

## Описание

Программа принимает предложение с клавиатуры и определяет количество слов в нём.

## Условие задачи

Что необходимо реализовать:
1. Считать предложение с клавиатуры.
2. Разделить предложение на отдельные слова.
3. Посчитать количество получившихся слов.
4. Вывести результат в консоль.

## Используемые пакеты и функции

- `fmt` — пакет для форматированного ввода и вывода данных.
- `bufio` — пакет для буферизированного ввода данных.
- `os` — пакет для взаимодействия с операционной системой.
- `strings` — пакет для работы со строками.
- `bufio.NewScanner()` — создаёт сканер для чтения входных данных.
- `scanner.Scan()` — считывает следующую строку.
- `scanner.Text()` — возвращает считанную строку.
- `strings.Fields()` — разделяет строку на слова, используя пробельные символы в качестве разделителей.
- `len()` — возвращает количество элементов в полученном срезе.
- `fmt.Print()` — выводит текст и значение в консоль.

## Принцип работы

1. Создаю сканер `scanner` с помощью `bufio.NewScanner(os.Stdin)`, чтобы считывать предложение целиком, включая пробелы.
2. Вывожу приглашение к вводу с помощью `fmt.Print()`.
3. Считываю предложение с клавиатуры с помощью `scanner.Scan()`.
4. Сохраняю введённую строку в переменную `str` с помощью `scanner.Text()`.
5. Использую `strings.Fields(str)`, чтобы разделить предложение на отдельные слова.
6. С помощью `len()` определяю количество элементов в полученном срезе и сохраняю результат в переменную `words`.
7. Вывожу количество слов в консоль.

## Пример работы

**Ввод:**
```text
Предложение: Hello world, how are you?
```

**Вывод:**
```text
Количество слов 5
```

**Ввод:**
```text
Предложение: Go is a great programming language
```

**Вывод:**
```text
Количество слов 6
```
