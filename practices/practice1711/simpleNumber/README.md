# Задание 3. Практика 17.11.2026 — Проверка простого числа

## Описание

Программа принимает целое число и определяет, является ли оно простым или составным.

## Условие задачи

Что необходимо реализовать:
1. Считать целое число с клавиатуры.
2. Проверить, что число больше или равно 1.
3. Проверить, делится ли число на какие-либо числа, кроме 1 и самого себя.
4. Определить, является ли число простым или составным.
5. Вывести результат в консоль.

## Используемые пакеты и функции

- `fmt` — пакет для форматированного ввода и вывода данных.
- `os` — пакет для взаимодействия с операционной системой.
- `fmt.Scan()` — считывает число с клавиатуры.
- `fmt.Println()` — выводит результат в консоль.
- `os.Exit()` — завершает выполнение программы с указанным кодом выхода.
