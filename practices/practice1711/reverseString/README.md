# Задание 1. Практика 17.11.2026 — Развернуть строку

## Описание

Программа принимает строку с клавиатуры и выводит её в обратном порядке.

## Условие задачи

Что необходимо реализовать:
1. Считать строку с клавиатуры.
2. Создать переменную для хранения результата.
3. Пройти по символам исходной строки в обратном порядке.
4. Добавить каждый символ к результирующей строке.
5. Вывести получившуюся строку.

## Используемые пакеты и функции

- `fmt` — пакет для форматированного ввода и вывода данных.
- `fmt.Scan()` — считывает строку с клавиатуры.
- `fmt.Println()` — выводит результат в консоль.
- `len()` — возвращает длину строки.
- `string()` — преобразует значение в строку.

## Принцип работы

1. Создаю две строковые переменные: `s` для исходной строки и `resultS` для результата.
2. Считываю строку с клавиатуры с помощью `fmt.Scan(&s)`.
3. Использую цикл `for`, который начинает перебор с последнего индекса строки (`len(s) - 1`) и движется к первому (`0`).
4. На каждой итерации преобразую текущий символ в строку с помощью `string(s[i])` и добавляю его к `resultS`.
5. Вывожу получившуюся строку с помощью `fmt.Println(resultS)`.

## Пример работы

**Ввод:**
```text
hello
```

**Вывод:**
```text
olleh
```

**Ввод:**
```text
golang
```

**Вывод:**
```text
gnalog
```
